My repo is a Cydia repository meant to have (most of) what you need for old devices

Add to Cydia

Packages

  • AppList — Lets tweaks read the list of installed apps
  • AppStoreFix — Fixes the App Store on iOS 3, 5 and 6
  • AppSync for iOS 4.0 — Install unsigned apps on iOS 4
  • AppSync for OS 3.1 — Install unsigned apps on iOS 3.1
  • AppSync Unified — Install unsigned/fakesigned iOS apps (iOS 5+)
  • Auxo — Re-imagined multitasking bar
  • Cydia Substrate — Code insertion platform
  • iFile — File manager and viewer
  • PreferenceLoader — Loads tweak preferences into Settings
  • TLSFix — Fixes SSL/TLS on iPhoneOS 2 to iOS 9
  • ultrasn0w — iPhone 4, 3G and 3GS software unlock
  • Veteris — Install older app versions on old devices
